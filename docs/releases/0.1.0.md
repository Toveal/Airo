First public release of Airo, a Windows utility that switches selection rectangle colors to match the monitor under your cursor.

- Separate outline and fill colors for each monitor, with a preview.
- Switch on monitor entry or on the first click after switching monitors.
- System tray, optional autostart, light and dark themes.
- English and Russian interface and tray menu.
- Original system colors restored on normal exit; recovery on the next launch after an interrupted run.

### Download

Download **Airo_0.1.0_x64-setup.exe** below. Windows 10/11, x64. The installer is per-user and does not require administrator rights. WebView2 is required; setup can download it if missing.

The app does not have a Windows publisher certificate, so SmartScreen may show an unknown-publisher warning. Updater signatures verify update artifacts; they do not remove this warning.

### Early release limitations

- Colors change globally for the Windows user session, following the cursor. Different colors are not rendered simultaneously on separate displays.
- The main effect is the drag-selection rectangle on the desktop and in Explorer. Explorer's selected-file styling is unchanged; classic applications may also use these system colors.
- Windows controls fill opacity; the preview is approximate.
- After a crash or forced termination, start Airo again and exit through its tray menu to restore the original colors.
- Update installation between two published versions and compatibility across Windows builds still need manual verification. You can always download a new installer from Releases.

Please report issues with your Airo version, Windows build and monitor setup. Reports in English or Russian are welcome.
